# homebrew-tap

Homebrew tap for [Agent Relay](https://github.com/RA1NM4KER/agent-relay).

```sh
brew install RA1NM4KER/tap/agent-relay
```

The formula (`Formula/agent-relay.rb`) downloads a prebuilt binary from Agent Relay's GitHub
Releases — no Rust toolchain is compiled during install.

Update instructions live in `agent-relay`'s own `docs/` (see `M5_FINAL_REPORT.md` for how this
formula is regenerated per release).
